 APEX SOLUTIONS Animation &amp; Effects System GSAP · ScrollTrigger · Lenis · SplitType · Swiper · Lottie Defines the animation, interaction, and motion language for the Apex Solutions website. The supplied premium engineering-site reference informs the visual direction; Apex branding and content remain original. 1. Global Motion System Primary animation engine: GSAP. Scroll-driven animation: GSAP ScrollTrigger. Smooth scrolling: Lenis. Headline splitting: SplitType. Carousels/touch interactions: Swiper. Complex lightweight illustrations: Lottie, only where justified. CSS handles micro-interactions such as link underlines, button hover, input focus, and simple card transforms. Do not introduce Framer Motion, Anime.js, AOS, Three.js, or Rive initially unless a specific requirement justifies them. 2. Global Page Lenis provides smooth scrolling and works with GSAP ScrollTrigger. Use a subtle scroll-progress indicator in Apex Gold #D7AB11. Desktop cursor: small Navy/Gold follower that expands over interactive elements. Disable custom cursor and reduce motion on touch devices and when prefers-reduced-motion is enabled. 3. Header / Navigation Initial load: logo, navigation, and CTA reveal with GSAP fade + vertical translation. At roughly 80–120px scroll, transition from large to compact header. Animate header height, padding, logo scale, background, and border. Scrolled state may use a white/translucent surface with subtle backdrop blur and 1px border. Navigation hover uses a restrained left-to-right underline reveal. 4. Hero Section The Hero is the most cinematic section. Use SplitType + GSAP for line-by-line headline reveals. Typical reveal: opacity 0?1 and Y 40px?0 with 0.08–0.12s stagger. Highlight selected headline words with Apex Gold #D7AB11. Hero engineering visual uses GSAP with SVG nodes, lines, grids, and subtle data particles. Use SVG path drawing via strokeDasharray/strokeDashoffset. Optional mouse parallax should be restrained to roughly 5–15px. 5. Trusted By / Technology Ecosystem GSAP infinite horizontal technology/client logo marquee. Target movement around 30–50px/sec. Pause marquee on hover when appropriate. Logo hover transitions from muted opacity to full opacity. 6. Capabilities / What We Build Use editorial card reveals instead of generic fade-ins. Cards enter with opacity 0?1 and Y 60px?0 using ScrollTrigger. Stagger card entrances around 0.08–0.15s. Featured visuals can use image scale 1.08?1. Hover: card translateY about -4 to -6px, visual scale about 1.03, and Gold accent line reveal. CSS is sufficient for hover states. 7. Engineering Approach Primary GSAP showcase section. Pin the section during the process journey using ScrollTrigger. Continuous path: Discover ? Architect ? Build ? Deploy ? Scale. Scrolling activates each step sequentially. Animate connecting SVG path, active node, step number, description, icon, and Gold progress indicator. Prefer one continuous engineering journey over five unrelated card fade-ins. 8. Solutions by Industry Use horizontal storytelling on desktop. Vertical scrolling controls horizontal movement through industries. Industry image hover: scale 1?1.04. Use a subtle overlay and Gold active indicator. Avoid aggressive scroll-jacking. 9. Products / Platforms Use pinned horizontal product storytelling with GSAP ScrollTrigger. Products transition sequentially while maintaining visual continuity. Inactive product visuals can move toward scale 0.96 and opacity 0.5; active visual returns toward scale 1 and opacity 1. Avoid hard cuts between products. 10. Technology Stack Represent the stack as an engineering system rather than a generic logo grid. Use SVG architecture/data-flow diagrams. Animate connection paths with strokeDashoffset. Use restrained Gold data particles travelling along selected paths. SVG + GSAP is sufficient initially; avoid Three.js unless later justified. 11. Why Apex + Impact / Metrics Use large numerical counters animated with GSAP ScrollTrigger. Animate values from 0 to final number over roughly 1.5–2.0 seconds. Use left/right reveal composition where appropriate. Metrics should feel energetic but remain credible and readable. 12. Case Studies Use image clip-path reveals when visuals enter the viewport. Typical sequence: clipped image reveal 100%?0% while image scale moves 1.08?1. Use ScrollTrigger for synchronized text and image storytelling. 13. Testimonials Use Swiper for desktop/mobile carousel behavior, touch interaction, and pagination. Use restrained active/inactive transitions. Quote marks may scale from 0.8?1 with opacity 0?1. Do not animate faces aggressively. 14. Our Process Use GSAP ScrollTrigger for sequential process activation. Sequence: Discover ? Architect ? Build ? Deploy ? Scale. Inactive steps remain subdued; active step uses Apex Gold as the progress accent. Optional circular progress uses an SVG circle with animated strokeDashoffset. Supporting principles can reveal sequentially with about 0.1s stagger. 15. Insights / Resources Keep this section as a compact strip. Use subtle ScrollTrigger reveals: Y 40px?0 and opacity 0?1. Images can scale from 1.05?1. Hover can scale the image to about 1.04 and move an arrow about 5px. Avoid heavy animation. 16. Final CTA Use a high-impact Apex Navy dark section. Background may contain subtle flowing lines, dots, radial glow, or geometric Apex patterns. Animate background elements slowly over approximately 10–20 seconds. CTA button may use Navy?Gold hover and a small arrow translation. Optional magnetic CTA movement should remain within approximately 6–8px. 17. Footer Keep footer motion quiet. Reveal columns with simple opacity + Y transition and small stagger. A very slow SVG wave or geometric movement may be used. Avoid scroll-jacking. 18. Page Transitions For multi-page navigation, use a subtle Apex Navy overlay transition. Recommended direction: overlay scaleY 1?0 to reveal the next page. Target duration: approximately 0.5–0.7s. 19. Micro-Interactions Links: Gold/Navy underline expands from 0?100%. Buttons: arrow translates approximately 5px on hover. Cards: subtle translateY(-4px). Images: subtle scale to approximately 1.03–1.04. Inputs: Navy border and restrained focus glow. Use CSS whenever an interaction does not need timeline or scroll orchestration. 20. Animation Principles Hero = cinematic. Engineering Approach = interactive. Technology Stack = technical. Metrics = energetic. Testimonials = restrained. Insights = subtle. Final CTA = impactful. Footer = quiet. Motion should reveal information, establish hierarchy, and connect sections—not exist merely as decoration. Prefer transform and opacity animation for performance. 21. Recommended Library Architecture GSAP: central animation orchestration and timelines. ScrollTrigger: viewport/scroll-driven animation, pinning, progress, and horizontal storytelling. Lenis: smooth scrolling. SplitType: typography splitting for hero and major heading reveals. Swiper: testimonials and genuine carousel interactions. Lottie: selected complex vector illustrations only. Lucide React: UI icons; not an animation engine. CSS: micro-interactions and basic hover/focus states. 22. Performance &amp; Accessibility Prefer transform and opacity for animation. Avoid repeatedly animating layout-triggering properties such as top, left, width, and height. Lazy-load heavy media and optimize images as WebP/AVIF. Use dynamic imports for animation-heavy components where useful. Respect prefers-reduced-motion: remove parallax, custom cursor, long transforms, and nonessential motion. Maintain keyboard navigation, visible focus states, semantic HTML, and accessible controls. 23. Apex Brand Motion Apex Navy #081E42 establishes authority. Apex Gold #D7AB11 creates moments of attention. White space creates premium perception. GSAP creates continuity. Engineering graphics create identity. Typography creates confidence. Target result: a premium engineering-company experience—not another generic IT/SaaS template.
